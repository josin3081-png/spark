# Spark

Spark is a modern, lightweight local dating web application built with Python and Flask. It allows users to create profiles, discover nearby people, swipe on candidate matches, and start chatting once a mutual match occurs.

![Spark Landing Page](static/images/hero.jpg)

## Features

- **User Authentication:** Secure signup, login, and password management.
- **Profile Customization:** Add profile details, bio, and preferences.
- **Match & Swipe System:** Discover local profiles and express interest.
- **Real-Time Chatting:** Instant messaging once two users match.
- **Demo Account Access:** Built-in credentials for fast testing and previewing.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite / SQLAlchemy
